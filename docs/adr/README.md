# Architecture decision records

The library's design decisions, one record each, numbered from 0001.  A
record states each decision with the evidence that earned it and its
status; the explanation of the design it records goes in a companion note
under `docs/notes/`, which the record links.

The records are as follows:

+  [ADR 0001: finite groups](0001-finite-groups.md), Proposed: the
   representation of a finite group and of its subgroups (M2-1, issue 5),
   with its companion note [`finite-groups.md`](../notes/finite-groups.md).
