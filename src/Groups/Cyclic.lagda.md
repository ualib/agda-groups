### The cyclic groups ℤ/n

This is the `Groups.Cyclic` module of the agda-groups library.

For every n ≥ 1, the **cyclic group ℤ/n** is `Fin n` under addition
modulo n: the sum of a and b is the remainder of a + b on division by n,
the identity is 0, and the inverse of a is the remainder of n − a.  It
is a group on `Fin n` (`Groups.Table`), so a finite group of order n with
the identity enumeration.  It is abelian, and **cyclic**, generated by
1: every element a is the power 1ᵃ, the sum of a copies of 1.  (In
Aschbacher, § 1, a group is cyclic when one element generates it, and,
after (1.10), the integers modulo n form the unique cyclic group of
order n, up to isomorphism.)  Cauchy's theorem (M4-2) acts with ℤ/p.

The hypothesis n ≥ 1 is agda-stdlib's instance `NonZero n`, the one its
division and remainder take, and which its primes supply.

#### Addition modulo n

Each operation is a remainder, agda-stdlib's `m mod n`, the element of
`Fin n` whose value is m % n.  Two remainders are equal when the values
they reduce are congruent modulo n, and a remainder may be taken inside
a sum or outside it.

```agda
module _ {n : ℕ} .{{_ : NonZero n}} where

  -- The value of m mod n is m % n.
  toℕ-mod : ∀ m → toℕ (m mod n) ≡ m % n
  toℕ-mod m = toℕ-fromℕ< (m%n<n m n)

  -- Numbers congruent modulo n have the same remainder.
  mod-≡ : ∀ {x y} → x % n ≡ y % n → x mod n ≡ y mod n
  mod-≡ {x} {y} e =
    toℕ-injective (trans (toℕ-mod x) (trans e (sym (toℕ-mod y))))

  -- A remainder may be taken inside a sum, on the left ...
  %-+ˡ : ∀ x y → (x % n + y) % n ≡ (x + y) % n
  %-+ˡ x y =
    trans  (%-distribˡ-+ (x % n) y n)
           (trans  (cong (λ z → (z + y % n) % n) (m%n%n≡m%n x n))
                   (sym (%-distribˡ-+ x y n)))

  -- ... and on the right.
  %-+ʳ : ∀ x y → (x + y % n) % n ≡ (x + y) % n
  %-+ʳ x y =
    trans  (%-distribˡ-+ x (y % n) n)
           (trans  (cong (λ z → (x % n + z) % n) (m%n%n≡m%n y n))
                   (sym (%-distribˡ-+ x y n)))

  -- An element of Fin n is its own remainder.
  toℕ-% : (a : Fin n) → toℕ a % n ≡ toℕ a
  toℕ-% a = m<n⇒m%n≡m (toℕ<n a)

  -- The remainder of 0 is 0.
  0%n : 0 % n ≡ 0
  0%n = m<n⇒m%n≡m (>-nonZero⁻¹ n)
```

The operations of ℤ/n, and the five group laws, each proved by comparing
the values of the two sides modulo n.

```agda
  infixl 6 _+ₘ_
  infix  8 -ₘ_

  -- Addition modulo n.
  _+ₘ_ : Fin n → Fin n → Fin n
  a +ₘ b = (toℕ a + toℕ b) mod n

  -- Zero.
  0ₘ : Fin n
  0ₘ = 0 mod n

  -- Negation modulo n.
  -ₘ_ : Fin n → Fin n
  -ₘ a = (n ∸ toℕ a) mod n

  -- One.
  1ₘ : Fin n
  1ₘ = 1 mod n

  -- The value of zero is 0.
  toℕ-0ₘ : toℕ 0ₘ ≡ 0
  toℕ-0ₘ = trans (toℕ-mod 0) 0%n

  -- Addition is associative ...
  +ₘ-assoc : ∀ a b c → (a +ₘ b) +ₘ c ≡ a +ₘ (b +ₘ c)
  +ₘ-assoc a b c = mod-≡ (begin
    (toℕ (a +ₘ b) + c′) % n   ≡⟨ cong (λ z → (z + c′) % n) (toℕ-mod (a′ + b′)) ⟩
    ((a′ + b′) % n + c′) % n  ≡⟨ %-+ˡ (a′ + b′) c′ ⟩
    (a′ + b′ + c′) % n        ≡⟨ cong (_% n) (+-assoc a′ b′ c′) ⟩
    (a′ + (b′ + c′)) % n      ≡⟨ %-+ʳ a′ (b′ + c′) ⟨
    (a′ + (b′ + c′) % n) % n  ≡⟨ cong (λ z → (a′ + z) % n) (toℕ-mod (b′ + c′)) ⟨
    (a′ + toℕ (b +ₘ c)) % n   ∎)
    where
    a′ = toℕ a
    b′ = toℕ b
    c′ = toℕ c

  -- ... and commutative.
  +ₘ-comm : ∀ a b → a +ₘ b ≡ b +ₘ a
  +ₘ-comm a b = cong (_mod n) (+-comm (toℕ a) (toℕ b))

  -- Zero is an identity on the left ...
  +ₘ-identityˡ : ∀ a → 0ₘ +ₘ a ≡ a
  +ₘ-identityˡ a =
    toℕ-injective (trans  (toℕ-mod (toℕ 0ₘ + toℕ a))
                          (trans  (cong (λ z → (z + toℕ a) % n) toℕ-0ₘ)
                                  (toℕ-% a)))

  -- ... and on the right.
  +ₘ-identityʳ : ∀ a → a +ₘ 0ₘ ≡ a
  +ₘ-identityʳ a = trans (+ₘ-comm a 0ₘ) (+ₘ-identityˡ a)

  -- Negation is an inverse on the left ...
  +ₘ-inverseˡ : ∀ a → -ₘ a +ₘ a ≡ 0ₘ
  +ₘ-inverseˡ a =
    mod-≡ (trans  (cong (λ z → (z + toℕ a) % n) (toℕ-mod (n ∸ toℕ a)))
                  (trans  (%-+ˡ (n ∸ toℕ a) (toℕ a))
                          (trans  (cong (_% n) (m∸n+n≡m (<⇒≤ (toℕ<n a))))
                                  (trans (n%n≡0 n) (sym 0%n)))))

  -- ... and on the right.
  +ₘ-inverseʳ : ∀ a → a +ₘ -ₘ a ≡ 0ₘ
  +ₘ-inverseʳ a = trans (+ₘ-comm a (-ₘ a)) (+ₘ-inverseˡ a)
```

#### The group ℤ/n

```agda
-- ℤ/n as a group on Fin n.
cyclic : (n : ℕ) .{{_ : NonZero n}} → FinGroup
cyclic n = fromEqs  n _+ₘ_ 0ₘ -ₘ_
                    +ₘ-assoc +ₘ-identityˡ +ₘ-identityʳ +ₘ-inverseˡ +ₘ-inverseʳ

infix 8 ℤ/_

-- ℤ/n as a finite group, of order n.
ℤ/_ : (n : ℕ) .{{_ : NonZero n}} → FiniteGroup 0ℓ 0ℓ
ℤ/ n = FinGroup.finiteGroup (cyclic n)

-- Its order is n, by definition.
∣ℤ/n∣≡n : (n : ℕ) .{{_ : NonZero n}} → FiniteGroup.order (ℤ/ n) ≡ n
∣ℤ/n∣≡n n = refl
```

ℤ/n is cyclic, generated by 1: the power 1ᵏ, the sum of k copies of 1
(`Groups.Subgroup.Notions`), has the value k % n, so every element a is
the power 1ᵃ.

```agda
  -- The power 1ᵏ has the value k % n ...
  toℕ-1^ⁿ : ∀ k → toℕ (1ₘ ^ⁿ k) ≡ k % n
  toℕ-1^ⁿ 0        = trans toℕ-0ₘ (sym 0%n)
  toℕ-1^ⁿ (suc k)  =
    trans  (toℕ-mod (toℕ 1ₘ + toℕ (1ₘ ^ⁿ k)))
           (trans  (cong₂ (λ x y → (x + y) % n) (toℕ-mod 1) (toℕ-1^ⁿ k))
                   (trans (%-+ˡ 1 (k % n)) (%-+ʳ 1 k)))

  -- ... so every element a is the power 1ᵃ: ℤ/n is generated by 1.
  1^ⁿ-toℕ : (a : Fin n) → 1ₘ ^ⁿ toℕ a ≡ a
  1^ⁿ-toℕ a = toℕ-injective (trans (toℕ-1^ⁿ (toℕ a)) (toℕ-% a))
```
